# 导航系统

这是一个自行实现的车辆导航系统，包含地图生成、路径计算和车流模拟功能。

## 已完成功能

### 核心数据结构
- **顶点(Vertex)**：表示地图中的一个地点，包含id、坐标和连接的边
- **边(Edge)**：表示地图中的一条道路，包含id、连接的顶点、长度、容量和当前车流量
- **图(Graph)**：表示整个地图，管理所有顶点和边
- **四叉树(QuadTree)**：用于空间索引，高效查询区域内的点
- **优先队列(PriorityQueue)**：用于最短路径算法

### 地图生成功能
- **随机点生成**：在二维空间中随机生成N个顶点（默认10000个）
- **Delaunay三角剖分**：创建合理的道路连接（依赖`scipy`库）
- **连通图生成**：确保图的连通性，避免不合理的交叉
- **数据导出**：支持将地图数据导出为JSON格式

### 前端可视化功能
- **Sigma.js渲染**：使用Sigma.js进行高性能地图可视化
- **地图显示功能**：输入坐标显示距离最近的100个顶点及相关边
- **地图缩放功能**：支持动态缩放，根据缩放级别显示不同密度的点
- **聚类可视化**：支持DBSCAN和KMeans聚类算法进行点聚合
- **图层切换**：支持原始数据图层和聚类图层的切换
- **实时交通显示**：动态显示道路拥堵状况，用不同颜色区分拥堵等级

### 路径规划算法
- **A*最短路径算法**：基于几何距离的最短路径计算
- **综合路况最短路径**：考虑实时交通状况的最快路径计算
- **路径可视化**：在地图上高亮显示计算出的路径
- **路径信息显示**：显示路径总距离/时间、经过的节点和边

### 交通流模拟
- **动态车流模拟**：实时模拟车辆在地图中的行驶
- **拥堵计算**：基于道路容量和当前车辆数计算拥堵等级
- **通行时间计算**：考虑拥堵状况的通行时间估算
- **车流分配**：车辆在相邻道路间的智能分配
- **实时更新**：通过WebSocket实现交通状况的实时更新

### 空间查询功能
- **四叉树空间索引**：高效的区域查询和最近邻搜索
- **附近节点查询**：根据坐标查找附近的节点
- **区域边界查询**：查询指定区域内的所有节点和边

### 聚类算法
- **DBSCAN聚类**：基于密度的聚类算法，适合不规则形状的聚类
- **KMeans聚类**：基于距离的聚类算法，适合规则形状的聚类
- **缩放级别聚类**：根据地图缩放级别自动选择合适的聚类算法

### API接口
- **地图数据API**：提供完整的地图数据
- **附近节点API**：根据坐标查询附近节点
- **路径计算API**：计算两点间的最短路径
- **交通模拟API**：控制交通模拟的开始和停止
- **聚类数据API**：提供不同缩放级别的聚类数据
- **网格拥堵API**：提供网格化的交通拥堵数据

### 后端服务
- **Flask Web服务器**：提供RESTful API接口
- **WebSocket支持**：实现实时数据推送
- **静态文件服务**：提供前端资源文件
- **CORS支持**：支持跨域请求

## 技术栈

### 后端
- **Python 3.x**：主要开发语言
- **Flask 3.1.0**：Web框架
- **Flask-SocketIO 5.5.1**：WebSocket支持
- **SciPy 1.15.3**：科学计算库，用于Delaunay三角剖分
- **NumPy 2.2.5**：数值计算库

### 前端
- **Sigma.js 3.0.2**：图形可视化库
- **Graphology 0.25.4**：图形数据结构库
- **Socket.IO 4.7.2**：实时通信
- **HTML5/CSS3/ES6**：现代Web技术

### 算法实现
- **A*算法**：路径规划
- **DBSCAN算法**：密度聚类
- **KMeans算法**：距离聚类
- **四叉树**：空间索引
- **Delaunay三角剖分**：地图生成

## 运行方式

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行主程序

```bash
python -m run
```

### 访问应用

启动后访问 `http://127.0.0.1:5000` 即可使用导航系统。

## 功能演示

1. **地图浏览**：启动应用后可以看到生成的地图，支持缩放和平移
2. **路径规划**：点击"计算最短路径"按钮，选择起点和终点进行路径规划
3. **交通模拟**：点击"开启车流模拟"按钮，观察实时交通状况变化
4. **图层切换**：使用"切换图层"功能在不同视图间切换
5. **聚类查看**：在不同缩放级别下查看聚类效果

## 注意事项

- 首次运行时会生成地图数据，可能需要一些时间
- 交通模拟功能会消耗较多计算资源，建议在性能较好的设备上运行
